Simple 20gt encoder prototype
## Features
- Encodes 1 box every 20gt
- 3 hexits
- Outputs the code with the box
- Expanding it is trivial
## Considerations
- It's still a prototype so it might have issues.
## Instructions
1. Encode boxes with the device; it will encode 1 box every 20gt.
2. After the code and box output is produced, what happens with the code and box after output is an exercise for the user.
## Compatibility
1.19+
