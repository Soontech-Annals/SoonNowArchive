**Tags:** *Functional*

## Features
- Idle Cart
- 2 hoppers unlocked (locking possible)
- Security features (SS2 check for input, hasItem to encode, ChestHasBeenReset and CartIsBack).
## Considerations
- Only boxes input
## Instructions
- Input in the hopper near the dropper line and press the note to process encoding.
