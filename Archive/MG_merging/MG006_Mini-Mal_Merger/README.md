An 'Applebloom' Merger Slice with control wiring.
## Features
- Faster slice mapping using a counter.
- Includes an output signal-strength sorter.
- Includes a box comparer that ensures the emptier box is loaded into the fuller box.
## Considerations
- Pairs require a fairly generous gap between insertion to the input stream.
## Instructions
1. Intended for use with a whitelister temp.
## Notes
Tested using Crea for over 8 million pairs.
