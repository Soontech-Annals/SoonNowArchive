A component that takes out two split boxes and merges them together.
## Features
- Counter for status outputs, making assignment one of the fastest for a water input merger; batching starts as soon as a slice is assigned.
- 5w Merger slice and front end, making it absolutely tiny.
- Relatively low piston activations and dust updates per slice.
- Lamp displays show which slice is running.
## Instructions
1. Put this after your temp and use a box comparer for speed optimization.
## Notes
Magma under the breaking piston is mandatory if it's a source block.
## Compatibility
1.19+
