A full feature splitter, largely a re-wire of Optics.
## Features
- Locally clocked for reliable empty box collection.
- Unstackable separation.
- As pausable as a splitter can be.
- In-slice distribution readout.
- Locks all hoppers with inventories at idle.
## Notes
- Box collection is not guaranteed when paused. This is effectively impossible with dueling hoppers anyway. 
- Technically, inputting a massive amount of boxes with unstackables can cause items to despawn. The fix would be having 4x hopperspeed unstackable/box filters. This issue exists on every splitter with global unstackable/box sorting and has never happened in survival.
## Compatibility
Designed in 26.3
