Very small splitter array, slices are 6x8 and the frontend is 5 wide.
## Features
- 8 splitters
- No status outputs from the slices which is why its so small, uses a counter in the frontend to keep track of the array.
## Negatives
- Slow distribution
- Basically no hopperlocking
- No unstackable separation, instead you must use a device that checks the output boxes for unstackables and removes said unstackables
## Instructions
1. Put boxes in the input and it splits them for you
2. There is no second step
